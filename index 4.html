Cara Kemas Kini GitHub & Kongsi Kepada Semua Guru

Gantikan fail index.html di GitHub supaya pautan web Cikgu terus hidup

1 Muat Turun Fail index.html & Upload ke GitHub

Tekan butang 1. Muat Turun index.html di bawah, kemudian buka halaman muat naik repositori GitHub Cikgu (teacherziela/sejarah_hub_ai_v4) dan seret fail index.html masuk untuk menggantikan fail lama.

2. Buka Halaman Upload GitHub

2 Cara Guru Lain Tengok & Update Rekod

  • Untuk Tengok: Kongsi pautan GitHub Pages Cikgu (https://teacherziela.github.io/sejarah_hub_ai_v4/) ke grup WhatsApp/Telegram panitia.
  • Untuk Update: Guru klik butang "Buka & Edit Sheet" di bahagian atas web untuk terus tambah pautan fail dalam Google Sheet "Pantia Sejarah Ai". Web ini akan automatik tarik data baharu bila dibuka!
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  var data = JSON.parse(e.postData.contents);
  sheet.appendRow([data.folder, data.title, data.form, data.year, data.author, data.desc]);
  return ContentService.createTextOutput(JSON.stringify({status: "ok"})).setMimeType(ContentService.MimeType.JSON);
}
